# ระบบเว็บแอปพลิเคชัน สั่งซื้อและเบิกอุปกรณ์สำนักงาน (Office Order Requisition System)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Auuzp/office-order)

ระบบสั่งซื้อและเบิกอุปกรณ์สำนักงานสำหรับองค์กร ออกแบบตามข้อกำหนดเพื่อรองรับพนักงานในเครือ **Illuspace (Thailand) Co., Ltd.**, **Live Lighting Co., Ltd.**, และ **True Innovation Tech Co., Ltd.** ให้สามารถส่งคำขอเบิกอุปกรณ์ได้อย่างสะดวก รวดเร็ว และให้ **Admin (ผู้ดูแลระบบ)** สามารถตรวจสอบ อนุมัติ และจัดการรายการอุปกรณ์ได้อย่างมีประสิทธิภาพ ใช้งานผ่านหน้าเว็บเบราว์เซอร์ 100%

---

## 🌟 ฟังก์ชันการทำงานหลัก (Core Features)

### 1. หน้าสำหรับพนักงาน (Employee Portal)
- **แสดงรายการอุปกรณ์สำนักงาน**:
  - ดูรูปภาพ หมวดหมู่ (เครื่องเขียน, เอกสาร, ไอที, อุปกรณ์ไฟฟ้า ฯลฯ) และรายละเอียดสินค้า
  - ระบบค้นหาและตัวกรองหมวดหมู่อุปกรณ์
  - เพิ่มอุปกรณ์ลงในตะกร้าเบิกสินค้า พร้อมระบุจำนวนที่ต้องการ
- **แบบฟอร์มการขอสั่งซื้ออุปกรณ์ (Requisition Form)** ครบถ้วนตามข้อกำหนด:
  - **รายการที่ต้องการซื้อ**: เลือกรายการพร้อมระบุหน่วยนับและจำนวน
  - **บริษัทของ User**: ตัวเลือกชื่อเต็มอย่างเป็นทางการ ได้แก่ `Illuspace (Thailand) Co., Ltd.`, `Live Lighting Co., Ltd.`, `True Innovation Tech Co., Ltd.`
  - **ผู้ขอซื้อ**: ชื่อ-นามสกุล และแผนก
  - **เหตุผลที่ขอซื้อ**: ตัวเลือกมาตรฐาน ได้แก่ `ชำรุด`, `สูญหาย`, `ไม่เคยได้รับ`, `พนักงานใหม่` พร้อมช่องกรอกรายละเอียดเพิ่มเติม
- **ระบบติดตามสถานะคำขอ (Order Tracking)**:
  - ตรวจสอบสถานะคำขอของตนเอง: 🟡 รออนุมัติ, 🟢 อนุมัติแล้ว, 🚚 กำลังจัดส่ง, 🔴 ปฏิเสธ
  - มีประวัติวันเวลาที่ขอ และชื่อผู้อนุมัติ (Admin)

### 2. หน้าสำหรับผู้ดูแลระบบ (Admin Portal)
- **ระบบยืนยันสิทธิ์ผู้อนุมัติ**: มีปุ่มสลับเข้าโหมด "ผู้ดูแลระบบ (Admin)" พร้อมระบบตรวจสอบรหัส PIN และเซสชันฝั่งเซิร์ฟเวอร์ (กำหนดรหัสผ่านผ่านตัวแปรสภาพแวดล้อม `ADMIN_PIN_HASH`)
- **การอนุมัติคำสั่งซื้อ (Approval Workflow)**:
  - หน้ารวมรายการรออนุมัติ พร้อมตัวเลขแจ้งเตือน (Pending Badge)
  - แสดงข้อมูลผู้ขอ, บริษัทเต็ม, เหตุผล, และรายการที่ขอเบิก
  - ปุ่ม **"อนุมัติคำสั่งซื้อ"**: เมื่อกดอนุมัติ ระบบจะบันทึกสถานะอนุมัติทันที
  - ปุ่ม **"ปฏิเสธ"**: สามารถระบุเหตุผลในการไม่อนุมัติ
- **การจัดการอุปกรณ์ (Inventory Management)**:
  - **Admin สามารถเพิ่มรายการอุปกรณ์ใหม่เข้าไปในระบบ** พร้อมฟังก์ชันอัปโหลดรูปภาพจากในเครื่องโดยตรง หรือระบุ URL รูปภาพ
  - แก้ไขหรือลบรายการอุปกรณ์ที่ไม่ต้องการได้ทันที
- **แดชบอร์ดสรุปและส่งออกข้อมูล (Dashboard & Export)**:
  - สรุปยอดคำขอเบิกแยกตามบริษัท
  - สถิติเหตุผลการขอเบิก (ชำรุด, สูญหาย, ไม่เคยได้รับ, พนักงานใหม่)
  - ปุ่ม **Export ไฟล์รายงาน Excel (.CSV)** ภาษาไทยถูกต้อง 100%

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ `start.bat` (สะดวกที่สุด)
เพียงดับเบิ้ลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์นี้ ระบบจะทำการเปิดเซิร์ฟเวอร์และเปิดหน้าเว็บเบราว์เซอร์ที่ `http://localhost:3001` ให้โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```powershell
# เปิดใช้งานระบบ
node server/index.js
```
จากนั้นเปิดเบราว์เซอร์ไปที่: **`http://localhost:3001`**

## 📁 โครงสร้างโปรเจกต์ (Project Structure)
```
office order/
├── start.bat                 # ไฟล์คลิกเปิดระบบสำหรับ Windows
├── package.json              # กำหนด dependencies และ scripts
├── vite.config.js            # การตั้งค่า Vite build & proxy
├── tailwind.config.js        # กำหนดชุดสี Illu, LL, True และฟอนต์ภาษาไทย
├── server/
│   ├── index.js              # Express API Server (REST Endpoints & ตัดสต็อก)
│   └── data/
│       ├── initialData.js    # ข้อมูลเริ่มต้นของอุปกรณ์และคำสั่งซื้อตัวอย่าง
│       ├── inventory.json    # ฐานข้อมูลสต็อกอุปกรณ์คงเหลือ (บันทึกอัตโนมัติ)
│       └── orders.json       # ฐานข้อมูลคำสั่งซื้อและประวัติการอนุมัติ
└── src/
    ├── main.jsx              # จุดเริ่มต้น React
    ├── App.jsx               # คอมโพเนนต์หลัก จัดการ State และสลับโหมด
    ├── index.css             # สไตล์ CSS และฟอนต์ Prompt
    └── components/
        ├── Navbar.jsx        # แถบเมนูด้านบนและปุ่มสลับโหมดพนักงาน/Admin
        ├── EmployeeCatalog.jsx # หน้ารายการอุปกรณ์พร้อมรายละเอียด
        ├── OrderModal.jsx    # แบบฟอร์มสั่งซื้ออุปกรณ์
        ├── OrderTracking.jsx # หน้าติดตามสถานะคำสั่งซื้อ
        ├── AdminApproval.jsx # หน้าอนุมัติคำสั่งซื้อโดย Admin
        ├── AdminInventory.jsx# หน้าจัดการเพิ่ม/แก้ไขรายการอุปกรณ์โดย Admin
        └── AdminDashboard.jsx# แดชบอร์ดสรุปยอดรายบริษัทและ Export Excel
```
