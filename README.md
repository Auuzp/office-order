# ระบบเว็บแอปพลิเคชัน สั่งซื้อและเบิกอุปกรณ์สำนักงาน (Office Order Requisition System)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Auuzp/office-order)

ระบบสั่งซื้อและเบิกอุปกรณ์สำนักงานสำหรับองค์กร ออกแบบตามข้อกำหนดเพื่อรองรับพนักงานในเครือ **Illu**, **LL**, และ **True** ให้สามารถส่งคำขอเบิกอุปกรณ์ได้อย่างสะดวก รวดเร็ว และให้ **พี่น้ำ (ผู้ดูแลระบบ)** สามารถตรวจสอบ อนุมัติ และจัดการสต็อกได้อย่างมีประสิทธิภาพ ใช้งานผ่านหน้าเว็บเบราว์เซอร์ 100%

---

## 🌟 ฟังก์ชันการทำงานหลัก (Core Features)

### 1. หน้าสำหรับพนักงาน (Employee Portal)
- **แสดงรายการอุปกรณ์สำนักงาน**:
  - ดูรูปภาพ หมวดหมู่ (เครื่องเขียน, เอกสาร, ไอที, อุปกรณ์ไฟฟ้า ฯลฯ) และรายละเอียดสินค้า
  - **แสดงจำนวนคงเหลือของอุปกรณ์ในระบบแบบเรียลไทม์**: แสดงป้ายสถานะชัดเจน (สีเขียว = พร้อมเบิก, สีส้ม = สต็อกเหลือน้อย, สีแดง = หมดสต็อก)
  - ระบบค้นหาและตัวกรองหมวดหมู่อุปกรณ์
- **แบบฟอร์มการขอสั่งซื้ออุปกรณ์ (Requisition Form)** ครบถ้วนตามข้อกำหนด:
  - **รายการที่ต้องการซื้อ**: เลือกรายการพร้อมระบุหน่วยนับ
  - **จำนวนที่ซื้อ**: ตรวจสอบจำนวนไม่ให้เกินสต็อกคงเหลือ
  - **บริษัทของ User**: ตัวเลือกชัดเจน ได้แก่ `Illu`, `LL`, `True`
  - **ผู้ขอซื้อ**: ชื่อ-นามสกุล และแผนก
  - **เหตุผลที่ขอซื้อ**: ตัวเลือกมาตรฐาน 4 ข้อ ได้แก่ `ชำรุด`, `สูญหาย`, `ไม่เคยได้รับ`, `พนักงานใหม่` พร้อมช่องกรอกรายละเอียดเพิ่มเติม
- **ระบบติดตามสถานะคำขอ (Order Tracking)**:
  - ตรวจสอบสถานะคำขอของตนเอง: 🟡 รออนุมัติ, 🟢 อนุมัติแล้ว (ตัดสต็อกแล้ว), 🔴 ปฏิเสธ
  - มีประวัติวันเวลาที่ขอ และชื่อผู้อนุมัติ (พี่น้ำ)

### 2. หน้าสำหรับพี่น้ำ (Admin / Approver Portal)
- **ระบบยืนยันสิทธิ์ผู้อนุมัติ**: มีปุ่มสลับเข้าโหมด "พี่น้ำ" พร้อมระบบรหัส PIN (เริ่มต้นคือ `1234`)
- **การอนุมัติคำสั่งซื้อ (Approval Workflow)**:
  - หน้ารวมรายการรออนุมัติ พร้อมตัวเลขแจ้งเตือน (Pending Badge)
  - แสดงข้อมูลผู้ขอ, บริษัท (`Illu`/`LL`/`True`), เหตุผล, รายการ และสต็อกคงเหลือ ณ ปัจจุบัน
  - ปุ่ม **"อนุมัติคำสั่งซื้อ"**: เมื่อกดอนุมัติ ระบบจะ **ตัดสต็อกอุปกรณ์โดยอัตโนมัติทันที**
  - ปุ่ม **"ปฏิเสธ"**: สามารถระบุเหตุผลในการไม่อนุมัติ และสต็อกจะไม่ถูกตัด
- **การจัดการอุปกรณ์และสต็อก (Inventory Management)**:
  - **พี่น้ำสามารถแอดรายการอุปกรณ์ใหม่เข้าไปในระบบ** พร้อมกำหนดรูปภาพ สต็อกตั้งต้น และหน่วยนับ
  - ปุ่มปรับสต็อกด่วน (+5, +10, -1) หรือแก้ไขรายละเอียดอุปกรณ์
  - ระบบแจ้งเตือนอุปกรณ์ที่สต็อกเหลือน้อย
- **แดชบอร์ดสรุปและส่งออกข้อมูล (Dashboard & Export)**:
  - สรุปยอดคำขอเบิกแยกตามบริษัท (`Illu` vs `LL` vs `True`)
  - สถิติเหตุผลการขอเบิก (ชำรุด, สูญหาย, ไม่เคยได้รับ, พนักงานใหม่)
  - ปุ่ม **Export ไฟล์รายงาน Excel (.CSV)** ภาษาไทยถูกต้อง 100%

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ `start.bat` (สะดวกที่สุด)
เพียงดับเบิ้ลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์นี้ ระบบจะทำการเปิดเซิร์ฟเวอร์และเปิดหน้าเว็บเบราว์เซอร์ที่ `http://localhost:3001` ให้โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```powershell
# เปิดใช้งานระบบ
node server/index.js
```
จากนั้นเปิดเบราว์เซอร์ไปที่: **`http://localhost:3001`**

## 📁 โครงสร้างโปรเจกต์ (Project Structure)
```
office order/
├── start.bat                 # ไฟล์คลิกเปิดระบบสำหรับ Windows
├── package.json              # กำหนด dependencies และ scripts
├── vite.config.js            # การตั้งค่า Vite build & proxy
├── tailwind.config.js        # กำหนดชุดสี Illu, LL, True และฟอนต์ภาษาไทย
├── server/
│   ├── index.js              # Express API Server (REST Endpoints & ตัดสต็อก)
│   └── data/
│       ├── initialData.js    # ข้อมูลเริ่มต้นของอุปกรณ์และคำสั่งซื้อตัวอย่าง
│       ├── inventory.json    # ฐานข้อมูลสต็อกอุปกรณ์คงเหลือ (บันทึกอัตโนมัติ)
│       └── orders.json       # ฐานข้อมูลคำสั่งซื้อและประวัติการอนุมัติ

    ├── App.jsx               # คอมโพเนนต์หลัก จัดการ State และสลับโหมด
    ├── index.css             # สไตล์ CSS และฟอนต์ Prompt
    └── components/
        ├── Navbar.jsx        # แถบเมนูด้านบนและปุ่มสลับโหมดพนักงาน/พี่น้ำ
        ├── EmployeeCatalog.jsx # หน้ารายการอุปกรณ์พร้อมสต็อกคงเหลือ

        ├── AdminApproval.jsx # หน้าอนุมัติคำสั่งซื้อโดยพี่น้ำ

        └── AdminDashboard.jsx# แดชบอร์ดสรุปยอดรายบริษัทและ Export Excel
```
